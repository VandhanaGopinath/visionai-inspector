# Corrective and Preventive Action (CAPA) Guide

This document describes what happens after a defect is detected and confirmed — the response process intended to contain the immediate issue and prevent recurrence.

## 1. Immediate Containment

**Section: Immediate Containment**

- Remove the rejected bottle from the production line immediately.
- If the defect type suggests a possible batch-wide issue (e.g., multiple contamination detections within the same batch, or a broken_large defect that suggests a mechanical handling fault), place the surrounding batch on hold pending investigation, per the Escalation Criteria in Document 3.

## 2. Investigation

**Section: Investigation**

- Review the inspection log (per Document 1, Section 12) for the affected unit and any recent units with similar findings.
- Determine whether the defect appears to be an isolated unit-level issue or a recurring pattern.
- Cross-reference the defect category and localization data with the relevant stage of production (e.g., filling, capping, handling) where feasible.

## 3. Possible Root Causes (by Defect Type)

**Section: Root Causes — Contamination**

Possible contributing factors for repeated contamination findings include: inadequate cleaning of filling equipment, environmental particulate introduction, or residue from upstream handling. (These are illustrative possibilities for this simulated project, not a diagnosed cause for any real facility.)

**Section: Root Causes — Broken (Small or Large)**

Possible contributing factors for repeated breakage findings include: mechanical impact during conveyor transport, improper handling at transfer points, or a defect introduced during the bottle-forming process upstream.

## 4. Corrective Action

**Section: Corrective Action**

Corrective action addresses the specific instance and any immediate systemic cause identified during investigation, such as adjusting equipment, retraining handling personnel, or repairing a mechanical fault identified as a contributing cause.

## 5. Preventive Action

**Section: Preventive Action**

Preventive action addresses the risk of recurrence more broadly, such as increasing inspection frequency for a specific defect type for a defined period, adjusting the automated system's sensitivity/threshold for that defect category, or scheduling more frequent equipment maintenance.

## 6. Verification

**Section: Verification**

After corrective/preventive action is taken, verification involves monitoring the defect rate for the affected defect type over a subsequent period to confirm the rate has returned to baseline. This project does not define a specific numeric baseline or monitoring window, since that would require real production throughput data.

## 7. Documentation

**Section: CAPA Documentation Requirements**

Each CAPA case should record: the triggering defect(s) and their document/defect_type reference, containment actions taken, investigation findings, root cause (if identified), corrective action, preventive action, and verification outcome. This creates a traceable link back to the original inspection record described in Document 1, Section 12.
